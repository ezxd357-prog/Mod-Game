UI / UX

มีตัวติดตั้งอัตโนมัติ ติดตั้งและถอนได้ในคลิกเดียว และสำรองไฟล์เดิมให้


คู่มือการใช้งาน - ม็อดภาษาไทย Vaygren: Lustful Temptation
==========================================================

วิธีติดตั้ง
1. คลิกขวาที่ไฟล์ ZIP > Extract All (ต้องแตกไฟล์ก่อน อย่าเปิดจากใน ZIP)
2. ปิดเกมให้เรียบร้อย
3. ดับเบิลคลิก Start_Installer.bat
4. รอให้โปรแกรมหาเกมเจอ (ถ้าไม่เจอ กด "เลือกโฟลเดอร์เกมเอง")
5. กดปุ่ม "ติดตั้ง" (สีเขียว)
6. เปิดเกม ถ้าขึ้น error ให้ปิดแล้วเปิดใหม่อีกรอบ

วิธีถอนการติดตั้ง
1. ปิดเกม
2. เปิด Start_Installer.bat
3. กด "ถอนการติดตั้ง" (สีแดง) แล้วกด Yes
เกมจะกลับเป็นภาษาอังกฤษ

หมายเหตุ
- ไฟล์ Start_Installer.bat, VaygrenThaiInstaller.ps1 และ thai.rpa
  ต้องอยู่โฟลเดอร์เดียวกัน
- เซฟเกมไม่ถูกแตะต้อง
- โปรแกรมสำรองไฟล์เดิมไว้ในโฟลเดอร์ Backup (อย่าลบถ้าจะถอนการติดตั้ง)
- อัปเดตม็อด: เอา thai.rpa ใหม่มาวางทับ แล้วกด "ติดตั้ง" ซ้ำ

ติดตั้งแล้วเกมยังเป็นภาษาอังกฤษ?
- ปิดเกมแล้วเปิดใหม่ 2 รอบ
- ติ๊ก "โหมดแก้ปัญหา: ใช้ชื่อไฟล์ zzz_thai.rpa" แล้วกด "ติดตั้ง" ใหม่
