เนื้อเรื่อง
แปลเนื้อเรื่องครบ 2 ตอนที่มีในเกมตอนนี้

ตอนที่ 1 "ลูกแมวของท่านนายพล"
ตอนที่ 2 "ค่ำคืนในฮัลลอน"

ครอบคลุมบทพูด บทบรรยาย ตัวเลือก ชื่อจุดเซฟ ชื่อตอน และซับไตเติลคัตซีน ชื่อตัวละครและชื่อสถานที่คงเป็นภาษาอังกฤษเดิม

UI / UX
แปลเป็นภาษาไทยทั้งหมด ได้แก่ เมนูหลัก เมนูระหว่างเล่น การตั้งค่า (กราฟิก เสียง ความเร็วข้อความ) หน้าการควบคุมปุ่มลัด ประวัติบทสนทนา เซฟ/โหลด ความทรงจำ/แกลเลอรี คำเตือนเนื้อหา และข้อความระบบของเกม เปลี่ยนฟอนต์ทั้งเกมเป็น LINE Seed Sans TH ให้อ่านภาษาไทยได้ชัด

เพิ่มเติม
มีตัวติดตั้งอัตโนมัติ ติดตั้งและถอนได้ในคลิกเดียว และสำรองไฟล์เดิมให้
